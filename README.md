### Folder Structure

```text
.
├───config                  <-- Configuration files
├───data
│   ├───1_raw               <-- Raw immutable data
│   ├───2_intermediate      <-- Typed data
│   ├───3_primary           <-- Domain model data
│   ├───4_feature           <-- Model features
│   ├───5_model_input       <-- Often called 'master tables'
│   ├───6_models            <-- Serialised models
│   ├───7_model_output      <-- Data generated by model runs
│   └───8_reporting         <-- Ad hoc descriptive cuts
├───notebooks               <-- Experimentation notebooks
├───references              <-- Datasheets, manuals, etc.
├───reports                 <-- Project documentation (PDF, LaTeX, etc.)
│   └───figures             <-- Figures used in documentation
├───src                     
│   ├───clearshape      <-- main package
└───test                    <-- Folder for code tests.
└───pyproject.toml          <-- File used to install the main package.
```

### Commit Messages

For easy identification commit messages should follow this template.

>`<commit type>: <commit message using the imperative>`
>
>`<additional describtion (optional)>`

Example: `chore: update README`

| Commit Type | Meaning                                                                   |
| ----------- | --------------------------------------------------------------------------- |
| feat        | New feature                                                                 |
| fix         | Bug fix                                                                     |
| style       | Change that do not alter the meaning of the code. (white space, formatting) |
| refactor    | Code changes that neither fixes a bug nor adds a feature                    |
| test        | Adding or correcting a test                                                 |
| doc         | Changes to the documentation (Comments, Docstrings, etc)                    |
| perf        | Changes that improves performance                                           |
| chore       | Task for updating; no change of production code                             |
| revert      | Reversion of a previous commit                                              |
